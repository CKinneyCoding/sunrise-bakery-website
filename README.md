# Sunrise Bakery Menu Demo

A simple static bakery menu page with an established visual system and product photography.

## Files
- `index.html`
- `styles.css`
- `images/` containing nine bakery item images

## Brand
- Terracotta: `#B85C3D`
- Deep terracotta: `#8F422D`
- Cream: `#FBF4E8`
- Sage: `#7B8F71`
- Butter gold: `#E7B85C`

The menu uses a repeated three-column grid pattern: product image, item name, short description, and price.
